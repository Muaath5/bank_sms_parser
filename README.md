# Banks SMS Messages Analyzer

A script that fetches all SMS messages from your Android phone and analyzes messages from Alinma and Alrajhi banks contacts for your financial management to produce a final JSON and CSV of your transactions.

## Requirements
- Enable USB Debugging

## Steps
```
./script.sh
```
